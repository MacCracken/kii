Frame is ~54 KB of ANSI escape sequences. First bytes (first cell):

  \x1b[38;5;0m\x1b[48;5;0m▀\x1b[38;5;0m\x1b[48;5;8m▀\x1b[38;5;8m\x1b[48;5;8m▀...

Format: per-cell `SGR foreground; SGR background; ▀` (U+2580 half-block).
Background carries the bottom-pixel color, foreground carries the
top-pixel color. Every row ends with an explicit SGR reset (`ESC [ 0 m`) before its
newline, so the frame cannot leave the terminal in a coloured state and
the next shell prompt isn't tinted. (Corrected at v1.5.1: this said the
reset was "implicit" and that stdout carried "no trailing escape" — the
opposite of both. `kii --width 80 … | tail -c 12` ends
`... 5 ; 0 m ▀ ESC [ 0 m \n`.)

Run produces exit code 0, no stderr output (unless --verbose).
