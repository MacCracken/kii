stdout:
  exit code: 1

The diagnostic fires when the file's leading bytes match none of the
four signatures kii accepts: PNG (89 50 4E 47 0D 0A 1A 0A), JPEG SOI
(FF D8), BMP ("BM"), or GIF ("GIF87a" / "GIF89a"). Per
`docs/guides/getting-started.md` § When kii rejects an image, this is
one of ~20 distinct error paths; each produces a specific diagnostic so
users can tell what failed.
